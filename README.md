# 🏝️ Astro Island (by ASTRO)

A custom, smooth desktop Dynamic Island for Windows built with Python (PyQt/PySide).

## ✨ Features
* 🎵 **Media Player Integration** — control your music directly from the island.
* 📊 **Hardware Monitoring** — keep an eye on your system performance.
* ⏱️ **Timers & Clocks** — convenient tools right at your cursor.
* 📋 **Clipboard Manager** — quick access to your copied history.
* ⚙️ **Advanced Settings Panel** — fully customizable look, feel, and behavior.
* 🚀 **Multi-threaded & Optimized** — runs smoothly without lags or freezes.

## 🛠️ Project Status
Core features are fully functional and performance-optimized. We are constantly improving it — feel free to leave your ideas, feature requests, or bug reports in the **Issues** tab!

## 🚀 Installation & Usage

1. **Prerequisites:** Make sure you have **Python 3.10 or newer** installed (get it from [python.org](https://www.python.org/)). *Important: check the box "Add python.exe to PATH" during installation.*
2. Extract this archive anywhere you like and double-click **`Установить.bat`** (Install script).
3. Select your preferred options in the window and click **"Install"**. An internet connection is required to download the necessary libraries.
4. The **"Astro Island"** shortcut will appear on your desktop and in your Start menu. In the Task Manager, the process will show up as **"Astro Island"**.

## 🔄 Updates & Removal

* **How to Update:** Simply run **`Установить.bat`** from the new version over your old installation — your settings will be preserved.
* **How to Uninstall:** Go to `Settings` → `Apps` → `Dynamic Island by ASTRO`, or use the **"Uninstall"** shortcut in your Start menu.

# 🏝️ Astro Island (by ASTRO)

Кастомный, плавный десктопный Dynamic Island для Windows, написанный на Python (PyQt/PySide).

## ✨ Возможности
* 🎵 **Интеграция с плеером** — управляйте музыкой прямо с островка.
* 📊 **Мониторинг системы** — следите за производительностью компьютера.
* ⏱️ **Таймеры и часы** — удобные инструменты всегда под рукой.
* 📋 **Менеджер буфера обмена** — быстрый доступ к истории скопированного текста.
* ⚙️ **Продвинутая панель настроек** — полностью настраиваемый внешний вид и поведение.
* 🚀 **Многопоточность и оптимизация** — работает плавно, без лагов и фризов.

## 🚀 Установка и использование

1. **Требования:** Убедитесь, что у вас установлен **Python 3.10 или новее** (скачать можно с [python.org](https://www.python.org/)). *Важно: при установке поставьте галочку «Add python.exe to PATH».*
2. Распакуйте этот архив в любое удобное место и дважды кликните по файлу **`Установить.bat`** (скрипт установки).
3. Выберите нужные параметры в окне и нажмите **«Установить»**. Для скачивания необходимых библиотек потребуется подключение к интернету.
4. Ярлык **«Astro Island»** появится на вашем рабочем столе и в меню «Пуск». В Диспетчере задач процесс будет отображаться как **«Astro Island»**.

## 🔄 Обновление и удаление

* **Как обновить:** Просто запустите **`Установить.bat`** из новой версии поверх старой — ваши настройки сохранятся.
* **Как удалить:** Перейдите в `Параметры` → `Приложения` → `Dynamic Island by ASTRO` либо используйте ярлык **«Удалить»** в меню «Пуск».
