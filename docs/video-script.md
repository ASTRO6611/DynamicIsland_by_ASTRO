## Что нужно для записи

- Остров запущен, тема чёрная (по умолчанию), масштаб экрана 100 %, разрешение 1920×1080.
- Записываем область острова крупно (700×292 в раскрытом виде) и общий план рабочего стола.
- Для сцены 8 модель должна быть уже загружена (первый запуск ~15 секунд) — иначе в кадр попадёт «загружаю модель».
- Для сцены 9 нужен играющий трек; если плеера нет — сцену сокращаем до микшера.
- Для сцены 10 запись экрана идёт 5–7 секунд, файл потом удаляем.
- Музыку и звуки не добавляем: голос + титры.
